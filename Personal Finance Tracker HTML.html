Backup & download

Your entries now auto-save in this browser under your current profile, so they're here at a glance when you reopen this page on this device. Nothing is sent anywhere. Export a backup regularly — that's how you move your books to another phone or computer, or recover if browser data is cleared.

Your data — My Finances

The JSON backup contains everything for the current profile — accounts, transactions, budgets, recurring items, and categories. The CSV is a spreadsheet-friendly copy of the ledger. Importing a backup replaces what's in the current profile and auto-saves over it. To keep profiles separate on another device, export each profile before you switch.

Take this file with you

Download a copy of this tracker as a single index.html — with the current profile's data baked in — ready to commit to a Git repository or drop onto a static host. It runs offline in any modern browser, on Windows or Android, and once opened it auto-saves in that browser from there.

Hosting it yourself

  1. GitHub: create a repository, add the downloaded file as index.html, then enable GitHub Pages (Settings → Pages → deploy from the main branch) to get a public URL.
  2. Netlify: drag the folder containing index.html onto Netlify's Sites page — it deploys instantly. You can host as many separate sites as you like on the free plan, so this and your geo tool can live side by side, each with its own URL.
  3. Editing at work: edit the file in the GitHub web editor or push changes from any machine; the host redeploys automatically. Keep your JSON backups separate — each browser keeps its own page state, so export/import is how you move your books between devices.
